# Book Framework

Репозиторий-фреймворк для написания, редактуры, документирования и сборки книг и рассказов.

## Идея

Каждая книга хранится как самостоятельный проект в `books/<slug>/`. Авторский текст никогда не перезаписывается редактурой: исходные главы находятся в `manuscript/chapters`, редакторская версия — в `manuscript/edited`.

Порядок глав и метаданные книги задаются в `book.config.json`. Справочник мира и канона хранится отдельно от рукописи в `docs/`.


## Жизненный цикл текста

1. Новая глава создаётся в `manuscript/chapters/`.
2. Это авторский оригинал. Редактура не должна менять его задним числом.
3. После редактуры версия главы помещается в `manuscript/edited/` с тем же именем файла.
4. Правила редактуры конкретного произведения фиксируются в `manuscript/edited/EDITING_RULES.md`.
5. Факты мира, персонажей и хронологии фиксируются в `docs/`.
6. Сборщик создаёт публикационные файлы в `dist/`.

## Правила редактуры

`EDITING_RULES.md` — обязательная часть проекта книги. В него необходимо записывать договорённости, которые редактор или ИИ должен соблюдать для всего произведения: авторский голос, допустимую степень переписывания, правила диалогов, юмора, терминологии, имён, POV, темпа, табуированные изменения и другие особенности.

Правила конкретной книги имеют приоритет над общими рекомендациями фреймворка.

## Формат book.config.json

```json
{
  "id": "example",
  "title": "Название книги",
  "annotation": "Короткая аннотация.",
  "status": "draft",
  "author": {
    "firstName": "Имя",
    "lastName": "Фамилия"
  },
  "language": "ru",
  "buildSource": "edited",
  "outputBaseName": "book",
  "genres": ["prose"],
  "chapters": [
    {
      "title": "Глава 1",
      "file": "01-chapter.txt"
    }
  ]
}
```

### Поля

- `id` — стабильный идентификатор проекта.
- `title` — название произведения.
- `annotation` — аннотация для каталога книг.
- `status` — например `idea`, `draft`, `editing`, `finished`, `published`.
- `author` — автор.
- `language` — язык книги.
- `buildSource` — `original` или `edited`.
- `outputBaseName` — имя файлов в `dist`.
- `genres` — жанры/теги.
- `chapters` — явный порядок глав. Порядок файлов в каталоге значения не имеет.

## Документация мира

`docs/` — внутренняя энциклопедия произведения. Рекомендуемые документы:

- `characters.md` — персонажи, характеры, отношения, состояние к текущему моменту;
- `world.md` — правила и устройство мира;
- `organizations.md` — компании, государства, группировки;
- `locations.md` — места;
- `technology.md` — технологии, магия, устройства и другие системы;
- `plot.md` — структура сюжета и основные арки;
- `timeline.md` — хронология;
- `continuity.md` — факты, которые особенно важно не нарушить в следующих главах.

Набор файлов можно расширять под конкретный проект.

## Команды

```sh
npm run new -- my-book
npm run build -- my-book
npm run build:txt -- my-book
npm run build:fb2 -- my-book
npm run build:all
npm run index
```

`new` создаёт каркас новой книги. `build` собирает TXT и FB2. `index` обновляет каталог книг ниже на основе их конфигов.
